# 👋 Welcome to Cosmic Meta

## What is Cosmic Meta?

Cosmic Meta is a collection of generative art series 100% stored and living on Ethereum blockchain. The whole collection incorporates several images bound to our imagination and creativity that we associate with our sensory experiences, while paying homage to the Universe's unbounded poetic sublimity.

We have currently 3 collections with over 300+ traits each; Cosmic Meta War Chicks, Cosmic Meta Pixel Art and Cosmic Meta molecules. These NFTs are created by a complex software via Artificial Intelligence and it took a very long time to create them! All the collections are united by one common lore and story line which will be a Metaverse based Play\&Earn cosmic game! Stay tuned!
